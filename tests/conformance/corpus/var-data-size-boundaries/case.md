# var-data-size-boundaries

Variable-length data at 0, 1, and exactly-aligned lengths. These are where a length prefix off by one stops being visible in a round-trip test.

3 frame(s), 264 payload byte(s).

Generated by `tools/CorpusBuilder`. `expected.sbe` was produced by replaying
through the reference queue. **Do not regenerate this to make a test pass** —
a changed `expected.sbe` in a diff is a behaviour change and must be justified
as one. See `knowledge/testing/l4-acceptance-replay.md`.
